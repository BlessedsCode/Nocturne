Установщик Nocturne для Windows x64.

- Nocturne регистрируется в Windows как доступный браузер для HTTP- и HTTPS-ссылок у каждого установившего пользователя.
- **Настройки → Основные и поиск → Сделать браузером по умолчанию** открывает системный выбор Windows.
- На последнем экране установщика появился необязательный пункт выбора браузера по умолчанию.
- Ссылки из других программ открываются при первом запуске и в уже работающем окне. Текущие вкладки и введённый текст сохраняются.

После обновления открой настройку браузера по умолчанию и подтверди выбор Nocturne в Windows. Профили сохраняются. SHA-256 опубликован рядом с установщиком; подписи издателя пока нет.
