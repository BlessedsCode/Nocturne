# Nocturne 0.10.10

Исправлена неполная блокировка рекламы YouTube. Добавлен локальный обработчик рекламных данных плеера: первоначальные данные, JSON, fetch и XHR. Рекламные карточки скрываются отдельными правилами. Включение, отключение и исключения для сайта учитываются до выполнения первых скриптов страницы. Обработчик нажимает штатную кнопку пропуска только во время рекламы; качество, громкость, скорость и позиция обычного видео не меняются.

SponsorBlock остаётся отдельной функцией для интеграций, размеченных сообществом. Новые форматы и реклама, встроенная сервером в видеопоток, могут потребовать дальнейших исправлений. Полная блокировка всех вариантов рекламы YouTube не гарантируется.

Убраны повторные полные обходы DOM при частых изменениях классов, косметическая обработка скрытых вкладок откладывается до возвращения. SponsorBlock использует события навигации вместо ежесекундного опроса адреса. Навигация iframe больше не заменяет адрес основной страницы вкладки.

Проверены 59 модульных тестов, HTTPS-сценарии с настоящим зарегистрированным preload (ранний запуск, fetch/clone, XHR, переключение настроек, исключения, SPA, изоляция Node.js), AdBlock/SponsorBlock и реальные сайты. YouTube в чистом тестовом профиле требует подтверждения входом: отсутствие видеорекламы в авторизованной сессии не заявляется как проверенный результат.

Установщик Windows x64. Закрой Nocturne перед обновлением; профили сохраняются. Выпуск пока без подписи издателя.
