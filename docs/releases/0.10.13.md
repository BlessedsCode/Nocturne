Исправлено отображение ответов HTTP 4xx/5xx. Браузер больше не скрывает загруженный документ сайта собственной страницей ошибки: видны объяснение отказа, штатные проверки доступа и ссылки для восстановления. Сетевые ошибки по-прежнему показываются отдельно. Исправление не отменяет ограничения доступа, установленные сервером сайта.

Проверены документы со статусами 403, 404, 429, 500, 503, переходы по их ссылкам, перенаправление на 403 и восстановление после разрыва соединения. Включены исправления окон авторизации из 0.10.12. Профили сохраняются при обновлении.
