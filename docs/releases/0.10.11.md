Установщик Nocturne для Windows x64.

- Исправлено исключение `Cannot read properties of undefined (reading 'id')` при сетевых запросах во время уничтожения содержимого вкладки. Добавлена проверка отсутствующих и уничтоженных нативных объектов.
- Добавлена обработка рекламных данных плеера YouTube и отдельные правила для рекламных карточек. Учитываются выключение AdBlock и исключения для сайта. SponsorBlock продолжает отдельно пропускать размеченные интеграции авторов.
- Убраны повторные полные обходы страницы в AdBlock. Косметическая обработка скрытых вкладок откладывается до возвращения; сетевая блокировка продолжает работать.
- Исправлена подмена адреса основной вкладки при навигации внутри iframe.

Обновление: **Настройки → О Nocturne → Проверить обновления → Скачать обновление → Установить**. Перед установкой закрой остальные окна Nocturne. Профили сохраняются.

Проверены 60 модульных тестов, сценарий уничтоженной вкладки с настоящими сетевыми запросами, повседневные сценарии, HTTPS-проверки обработчика YouTube и запуск упакованного приложения. Полная блокировка всех форматов рекламы YouTube не гарантируется. Установщик пока без подписи издателя; SHA-256 опубликован рядом с файлом.
