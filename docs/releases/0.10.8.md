Установщик для Windows x64: **Nocturne-Setup-0.10.8-x64.exe**.

- Встроенный блокировщик рекламы Ghostery + EasyList/EasyPrivacy: фильтрация запросов, скрытие элементов, обновление правил и исключения для сайтов.
- SponsorBlock через API: пропуск спонсорских интеграций на YouTube и кнопка «Вернуть». Аккаунт и API-ключ не нужны.
- Новый тёмный установщик с Мон-Сен-Мишелем в стиле браузера.

Настройки функций: **Настройки → Безопасность**. Профили сохраняются при обновлении.

Проверены 51 модульный тест, повседневные сценарии и публичные сайты. На тестовом подключении YouTube требовал вход «не бот», поэтому реальное воспроизведение с пропуском не подтверждено; API и контроллер проверены отдельно. Полная блокировка всей рекламы и незаметность для анти-AdBlock не гарантируются.

SHA-256 опубликован рядом с установщиком. Установщик пока без подписи издателя.
