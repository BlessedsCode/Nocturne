В контекстном меню вкладки добавлены «Отключить звук вкладки» и «Включить звук вкладки». На заглушённой вкладке отображается значок динамика; нажатие возвращает звук, не переключая активную вкладку. Отключается только выбранная вкладка, независимо от сайта и его плеера.

Состояние сохраняется при переходах, сне/пробуждении вкладки и восстановлении сеанса. Проверены собственные API Chromium для отключения звука, работа с фоновыми вкладками, меню, значок и перезапуск браузера.
