# Nocturne 0.10.22

AI-помощник Gemini с бесплатным веб-поиском Nocturne, кликабельными ссылками и источниками. Ответы оформляются в виде заголовков, списков, таблиц и блоков кода с копированием. Поддерживаются новые ключи Google AI Studio формата AQ; ключ хранится зашифрованным Windows.

Объединены локальные изменения и последняя версия GitHub: сохранены настройки стекла с живым образцом и локальные правила фильтрации контента YouTube. Исходники организованы в src/ и tests/.

Windows x64. Установщик сохраняет профиль и настройки. API-ключ каждый пользователь подключает самостоятельно. Установщик пока без подписи издателя. SHA-256 опубликован рядом с файлами.
