# Встроенная блокировка рекламы и SponsorBlock

В Настройках → Безопасность появились два независимых переключателя, обновление фильтров и счётчики. EasyList/EasyPrivacy поставляются с приложением: первый запуск не зависит от доступности серверов списков. Исключения рекламы и трекеров общие; опасные домены проверяются независимо от этих исключений.

Ghostery обрабатывает сетевые правила и обычные CSS-фильтры, включая динамически появляющиеся элементы. Скриптлеты и расширенные селекторы пока не выполняются. Это не обещание всей функциональности uBlock Origin или гарантированной блокировки видеорекламы YouTube. Защита сертификатов, sandbox и изоляция сайтов сохранены.

SponsorBlock запрашивает только категорию sponsor, действие skip. Сервер получает IP и четыре символа SHA-256 ID видео, а не полный ID/URL. Таймкоды проверяются, кэш ограничен 100 роликами и 10 минутами. Запросы объединяются, таймаут 8 секунд, при ошибке/429 действует пауза. Нет отправки просмотров, голосов и пользовательского аккаунта. Кнопка «Вернуть» отменяет пропуск без повторного немедленного перескакивания. При недоступности API видео продолжает работать.

Источники и атрибуция: resources/adblock/SOURCES.md.
