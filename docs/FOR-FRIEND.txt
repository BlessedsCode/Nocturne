NOCTURNE — ЗАПУСК НА WINDOWS

1. Распакуй архив целиком в отдельную папку.
2. Запусти Nocturne.exe. Остальные файлы рядом с ним тоже нужны.
3. Node.js и npm для этой сборки не требуются.

ПЕРВЫЙ ЗАПУСК
Выбери цвет интерфейса, фон и поисковую систему.
Затем Nocturne найдёт установленные браузеры и предложит перенос паролей.
Отметь браузеры галочками → «Перенести выбранные пароли».
Доступные пароли переносятся автоматически и сохраняются зашифрованными.
Если у Zen / Firefox есть основной пароль, Nocturne попросит его один раз.
Защита App-Bound некоторых Chromium-браузеров может не позволить перенос.
Такие записи показываются отдельно и не считаются перенесёнными.
CSV и ручной экспорт доступны в разделе «Резервный способ».
Начальную настройку можно пропустить или повторить в «О браузере».

ПОИСК ВО ВСЕХ СИСТЕМАХ
Кнопка справа в адресной строке собирает результаты на одной странице.
Источники: Google, Яндекс, DuckDuckGo, Bing, Brave Search, Yahoo и Ecosia.
У каждой ссылки указаны источники и места в их выдаче. Повторы объединяются.
Можно показать только выбранный источник. Совпадения нескольких источников выше.
Страницы загружаются по две, повторный запрос использует кэш на две минуты.
Некоторые сервисы требуют капчу, согласие или блокируют чтение выдачи.
Тогда появится статус и кнопка открытия обычной выдачи; капчи не обходятся.
Запрос передаётся всем семи системам только по нажатию этой кнопки.

ПОИСК НА АНГЛИЙСКОМ
По умолчанию русский запрос дополнительно переводится и ищется на английском.
Перевод MyMemory показан над результатами; его можно изменить вручную.
Сервису MyMemory передаётся только текст запроса, история не отправляется.
У сервиса есть ограничения длины и дневная квота. При ошибке введи перевод сам.
Галочка «Искать и на английском» отключает дополнительные английские запросы.
У ссылок показаны язык запроса, поисковик и место в выдаче.
Одна система учитывается один раз, даже если нашла ссылку на двух языках.
В сортировке учитывается совпадение с темой запроса; первые результаты разнообразнее.

Если источник требует капчу или согласие, нажми «Открыть проверку».
Пройди её самостоятельно на странице источника и закрой окно.
Общий поиск повторится с теми же cookies и без старого кэша.
Кнопка «Повторить без кэша» заново проверяет источники в любое время.

Фон можно поменять: Настройки → Внешний вид → Фон новой вкладки.
Доступны Мон-Сен-Мишель и прежний портрет.

РАСКЛАДКА ГЛАВНОЙ
Внизу справа нажми «Изменить раскладку».
Тяни поиск и быстрые ссылки за заголовки, а за угол — меняй ширину.
«Привязка» выравнивает по сетке и центру; Alt временно отключает её.
«Готово» сохраняет, «Отмена» или Escape возвращает сохранённый вариант.
«Сбросить» возвращает исходное расположение; затем нажми «Готово».
Режим также доступен в настройках внешнего вида.

ПОДСКАЗКИ В ПОИСКЕ
Нажми на поиск на главной или адресную строку.
Пустое поле показывает недавно открытые и часто посещаемые сайты.
При вводе появляются совпадения из истории и подсказки поисковика.
Выбирай мышью или стрелками, Enter открывает, Escape закрывает список.
Интернет-подсказки можно отключить: Настройки → Основные и поиск.
Для них вводимый запрос отправляется выбранной поисковой системе.
История не отправляется; адреса и URL-параметры для подсказок исключены.
Если поисковик недоступен, история и обычный поиск продолжают работать.

Локальная блокировка опасных доменов/трекеров уже включена.
Файлы проверяются Microsoft Defender, если он доступен в Windows.
Сборка не подписана издателем; автоматических обновлений пока нет.

ОБЛАЧНАЯ ЗАЩИТА GOOGLE (ПО ЖЕЛАНИЮ)

Настройки → Безопасность → Подключить облачную защиту Google.

Нажми «Открыть Google Cloud» и создай собственный проект.
Включи Safe Browsing APIs. В APIs & Services → Credentials создай
API key. В ограничениях ключа разреши только Safe Browsing APIs.

В Nocturne выбери Safe Browsing, вставь свой ключ и нажми
«Проверить и включить». Приложение отправит Google тестовый адрес
https://example.com/ и включит облачную проверку после успешного ответа.
Если доступа нет, появится подсказка: ключ, API, ограничения, квота или сеть.

Safe Browsing предназначен для некоммерческого использования.
Облачная проверка передаёт проверяемые адреса Google.
API-ключ сохраняется зашифрованным в твоём профиле Windows.
Он не входит в архив, и пересылать его другому человеку не требуется.
Твой аккаунт, ключи, история и пароли не синхронизируются с отправителем.

Профиль этой сборки: %APPDATA%\NocturneSecure
Он отделён от профиля запуска из исходников через start.cmd.

Ctrl+H → крестик у записи / флажки и «Удалить выбранное» / «Удалить всю историю».
Очищается только текущий профиль.

Для Zen: Настройки → Пароли → галочка Zen Browser → «Перенести выбранные пароли».
Перенос выполняется в текущий профиль Nocturne. CSV для доступных записей не нужен.
Для недоступного источника раскрой резервный способ с экспортом CSV.

Инструкция Google:
https://developers.google.com/safe-browsing/v4/get-started
