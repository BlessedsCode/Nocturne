# Nocturne

Персональный браузер для Windows на Electron 45 / Chromium. Это самостоятельное приложение на движке Chromium через Electron, а не форк исходного кода Chromium.

## Запуск

Двойной щелчок по `start.cmd`. На новом компьютере установите Node.js 22.12+ и выполните `npm install`, затем `npm start`. Если браузер уже открыт после обновления исходников, закройте его и запустите снова.

## Возможности

- Вкладки, адресная строка, назад/вперёд, обновление, семь поисковых систем: Google, Яндекс, DuckDuckGo, Bing, Brave Search, Yahoo и Ecosia.
- Общая выдача на одной странице: отметки источников, фильтры и объединение одинаковых ссылок. Ссылки ранжируются по reciprocal rank fusion — учитываются места в выдаче каждого источника. Две изолированные страницы одновременно, отмена при закрытии, кэш в памяти на две минуты. Доступность зависит от сайтов: капчи, согласия и нераспознанная выдача показываются явно с переходом к оригиналу; гарантированного доступа ко всем источникам нет.
- Первый запуск с выбором цвета интерфейса, фона, анимаций и поисковика. После этого — обнаружение Chrome, Edge, Firefox, Zen Browser, Brave, Vivaldi, Opera и Яндекс Браузера по известным папкам установки и App Paths Windows. Найденные браузеры выбираются галочками для локального автоматического переноса паролей. CSV и ручной экспорт остаются резервным способом.
- Мон-Сен-Мишель и готический портрет, стартовая страница с перемещением и изменением ширины поиска и быстрых ссылок.
- Раздел «Безопасность»: локальная блокировка опасных доменов, сторонних трекеров и рекламы, обновление списков, предупреждение HTTP, сканирование загрузок Microsoft Defender, проверка версии движка. Облачные API Safe Browsing / Web Risk подключаются отдельно со своим ключом и разрешением передачи адресов.
- Единые настройки в левом верхнем углу: Glass Lab, пароли, основные параметры. Прозрачность, размытие, яркость, насыщенность, оттенок и текстура сохраняются локально.
- Плавное появление и закрытие панелей, переходы и отклик элементов. Анимации можно выключить; системное предпочтение уменьшения движения учитывается.
- Быстрые ссылки: добавление через «+», редактирование, удаление, перемещение вверх/вниз, независимое закрепление на главной и в боковой панели. Крестик при наведении открепляет только с текущего места. Правый клик открывает меню; вернуть закрепление можно в редакторе ссылок. Избранное хранится отдельно.
- Фавиконки загружаются автоматически с сайтов: приложение читает link rel=icon / apple-touch-icon из HTML, пробует /favicon.ico и запоминает результат на диске. Во вкладках также используется событие favicon от Chromium. Иконки сайтов не подбираются вручную. Если доступной иконки нет, показывается нейтральный символ.
- Настройки открываются отдельной страницей с боковой навигацией и поиском. Работают восстановление сеанса, фоновое открытие вкладок, выбор соседней вкладки после закрытия, масштаб сайтов, орфография, сохранение истории, Do Not Track, очистка кэша/cookies/истории, разрешения сайтов и папка загрузок. Do Not Track лишь передаёт предпочтение, а не блокирует слежение.
- Загрузки с системным диалогом сохранения, прогрессом, паузой, продолжением, отменой, открытием файла и показом в папке. История сохраняется. Удаление из списка не удаляет файл. Незавершённые загрузки после перезапуска отмечаются прерванными; продолжение между запусками пока не реализовано.

## Пароли

На первом запуске или в Настройки → Пароли программа находит браузеры и профили с данными паролей. Отметь нужные браузеры галочками → «Перенести выбранные пароли». Все доступные записи из найденных профилей выбранных браузеров переносятся в текущий профиль Nocturne. Результаты по каждому источнику: добавлено, обновлено, пропущено, защищено, ошибок. Поиск только проверяет пути и метаданные; чтение и расшифровка начинаются после нажатия кнопки переноса.

Zen / Firefox: используется установленная библиотека NSS рядом с exe и базы logins.json / key4.db в режиме чтения. Если установлен основной пароль, появляется поле для его ввода; он используется один раз и не сохраняется. Для Chromium-браузеров поддержаны доступные текущему пользователю Windows DPAPI и AES-GCM v10/v11 записи из Login Data. App-Bound v20 и неизвестные версии не обходятся: показывается ограничение, даже если другие записи перенесены успешно. Доступность зависит от исходного браузера, профиля, версии/разрядности NSS и блокировки файлов. Гарантировать полностью автоматический перенос из любого браузера нельзя.

Локальный модуль Windows запускается без повышения прав; секреты передаются по закрытым stdin/stdout-каналам в памяти, без открытых файлов CSV и без отправки в сеть. В интерфейс передаются только результаты и число записей. Исходные базы не изменяются. CSV и ручное открытие менеджера паролей находятся в свёрнутом разделе «Резервный способ».

API NSS описан в [официальном заголовке Mozilla](https://searchfox.org/firefox-main/source/security/nss/lib/pk11wrap/pk11sdr.h). Ограничение App-Bound объясняется в [публикации Chromium](https://security.googleblog.com/2024/07/improving-security-of-chrome-cookies-on.html).

Поддерживаются колонки `url,username,password` из Chrome, Edge, Firefox, Zen и совместимых экспортов; также распознаются `origin`, `hostname`, `login_uri`, `login_username`, `login_password`. Принимаются UTF-8 и UTF-16 с BOM, разделители запятая, точка с запятой и табуляция. Кавычки и переносы строк внутри паролей сохраняются. Некорректные адреса и пустые пароли пропускаются с отчётом; если подходящих записей нет, появляется объяснение. Повторные записи с тем же origin и логином обновляются. Максимальный размер CSV — 20 МБ.

Хранилище `passwords.enc` в профиле приложения шифруется через Electron safeStorage и Windows DPAPI. Если шифрование недоступно, импорт не выполняется. Пароли не передаются в интерфейс настроек: там только сайты и логины. Защита привязана к пользователю Windows; отдельного мастер-пароля пока нет. Другие программы с правами этого пользователя не исключены из модели доступа Windows.

Для использования откройте страницу входа, затем Настройки → Пароли → «Заполнить» у нужного логина. Поддерживается видимая форма в основном документе, точное совпадение origin (протокол + домен + порт), только HTTPS; форма не отправляется автоматически. Пароли из iframe и многошаговые нестандартные формы могут потребовать ручного ввода. Можно искать и удалять записи. Автоматическое сохранение новых паролей пока не реализовано.

Приложение читает только выбранные источники после запуска переноса. Содержимое паролей не включается в отчёты, журналы или снимки тестов. Если используешь резервный CSV, после импорта удали экспортированный файл самостоятельно: он содержит открытые пароли. Для разработки и тестов создавались отдельные синтетические хранилища NSS и Chromium.

## Профили и история

Вход в личный профиль скрыт в разделе «О Nocturne» и реагирует на двойной клик по невидимой области внизу справа. В личном профиле та же область возвращает к основному. Оба окна имеют заголовок «Nocturne» без метки профиля. При входе показывается короткая заставка «18+ ONLY» с предупреждением и индикатором перехода, затем она плавно исчезает. При отключённых анимациях и системном уменьшении движения предупреждение остаётся статичным. После входа меток профиля в интерфейсе нет. Личный профиль запускается в отдельном окне с отдельной папкой `profiles/personal` внутри текущего профиля приложения. Раздельны cookies, хранилища сайтов, история, подсказки истории, пароли, избранное, закреплённые ссылки, настройки и список загрузок. В личном профиле нет начальных быстрых ссылок; онлайн-подсказки и облачная проверка по умолчанию выключены. Сайты не добавляются в быстрые ссылки автоматически. История сохраняется локально и отдельно, а не удаляется при закрытии; в настройках приватности её можно отключить. Это не режим анонимности и не отдельный пользователь Windows. Скачанные файлы по умолчанию попадают в обычную папку загрузок Windows; для каждого профиля можно задать другую папку.

Настройки → История (Ctrl+H): крестик удаляет одну запись, флажки и «Удалить выбранное» — несколько, «Выбрать все найденные» учитывает фильтр поиска. «Удалить всю историю» запрашивает подтверждение и действует только на текущий профиль. Более 100 записей доступны кнопкой «Показать ещё». Удаление посещений не удаляет избранное, пароли или cookies.

В подсказках у сайтов группы «Часто» есть крестик. Он скрывает сайт из начальных рекомендаций текущего профиля и сохраняет выбор после перезапуска. История посещений и её поиск при вводе запроса остаются доступны.

## Горячие клавиши

F12 / Ctrl+Shift+I — инструменты разработчика; Ctrl+Shift+J — консоль; Ctrl+Shift+C — выбор элемента. Работают и в готовой сборке.

Ctrl+L / Alt+D / F6 — адрес; Ctrl+T/W — новая/закрыть вкладку; Ctrl+Shift+T — вернуть закрытую; Ctrl+Tab / Ctrl+Shift+Tab — переключение; Ctrl+1…9 — выбор вкладки. F5 / Ctrl+R — обновить; Ctrl+F5 / Ctrl+Shift+R — обновить без кэша; Alt+стрелки — история; Alt+Home — главная; F11 — полный экран.

Ctrl+F — поиск на странице; F3 / Shift+F3 — следующее/предыдущее совпадение. Ctrl+плюс/минус — масштаб; Ctrl+0 — масштаб из настроек. Ctrl+J — загрузки; Ctrl+H — история; Ctrl+D — избранное; Ctrl+P — печать; Ctrl+S — сохранить HTML; Ctrl+U — просмотр текущего DOM; Ctrl+Shift+Delete — очистка данных; Escape — закрыть панель. Сочетания с буквами учитывают русскую раскладку.

Меню правой кнопки учитывает выделение, ссылки, изображения и поля ввода: копирование, поиск, перевод на английский, сохранение, снимок видимой страницы и исследование элемента. Копирование и поиск выделенного текста в поле пароля отключены.

При открытии панелей и подсказок над сайтом показывается снимок текущего вида страницы вместо главной. Сам документ остаётся открытым: после закрытия сохраняются прокрутка и введённый текст. Фон панели не является живым видео.

## Проверки

- `npm test` — адреса, блокировка привилегированных схем, CSV, шифрованное хранение, обновление записей и ошибки хранилища.
- `npm run test:controls` — реальные F12, горячие клавиши, поиск по странице, контекстные меню, сохранение PNG/HTML и просмотр DOM.
- `npm run test:overlays` — панели над сайтом без подмены главной, сохранение документа, прокрутки и несохранённого текста.
- `npm run test:recovery` — переходы после HTTP-ошибок, возврат на главную, восстановление упавшего процесса страницы, быстрое закрытие вкладок, перезагрузка интерфейса и некорректные данные интерфейса.
- `npm run test:profiles` — выборочное удаление истории, удаление по фильтру, подтверждение полной очистки, синтетический экспорт Zen, шифрование Windows и изоляция двух одновременно работающих профилей с перезапуском.
- `npm run test:auto-import` — реальные синтетические NSS-базы (включая основной пароль), Windows DPAPI + AES-GCM, SQLite внутри Electron, интерфейс с галочками, отклонение App-Bound и шифрованное хранилище назначения. Нужен установленный Zen или Firefox для NSS-библиотеки; реальные пароли не используются.
- `node smoke.cjs` — Chromium, интерфейс, example.com, изоляция сайтов, избранное и сетевые ошибки.
- `node security-smoke.cjs` — опасные переходы и редиректы на безопасных тестовых доменах, трекеры, подтверждение HTTP, изоляция, облачные ошибки на тестовых ответах и реальная проверка безвредного файла Defender.
- `node settings-smoke.cjs` — получение иконки из HTML тестового сайта и отображение на трёх поверхностях, независимое открепление, поиск настроек, реальный масштаб, DNT, очистка истории/cookies, папка автоматических загрузок без перезаписи, восстановление сеанса и компактная вёрстка.
- `node features.cjs` — редактор ссылок, импорт через диалог с синтетическим CSV, реальный Windows safeStorage, заполнение формы на точном origin, отказ на другом origin, скачивание с локального HTTP-сервера, пауза/продолжение и сохранение после перезапуска. Для проверки кнопок открытия подменяются только системные обработчики открытия; тестовый файл действительно скачивается. Проверки используют отдельные профили в `artifacts/` и не затрагивают пользовательские данные. Снимки интерфейса — в `artifacts/`.

Сайты работают с выключенным Node.js, включёнными sandbox/contextIsolation и без привилегированного preload. Камера/микрофон, геолокация и уведомления по умолчанию заблокированы; в настройках можно включить запрос подтверждения. Разрешение выдаётся только для основного HTTPS-сайта и действует в текущем запуске. Остальные разрешения отклоняются. Очистка данных требует подтверждения и не удаляет пароли/избранное. Ошибки сертификатов не обходятся. Расширения Chrome, синхронизация и автоматическое обновление пока отсутствуют.

Портрет создан специально для проекта с imagegen. `assets/reference.jpg` — предоставленный пользователем визуальный референс, не используется в интерфейсе.

## Защищённая локальная сборка

`npm run package` → `release/Nocturne-win32-x64/Nocturne.exe`. Это сборка с ASAR integrity, отключёнными служебными режимами Electron и шифрованием cookies; подписи издателя и автоматических обновлений пока нет. Использует отдельный профиль `%APPDATA%/NocturneSecure`, чтобы не смешивать шифрованные cookies с профилем разработки. Старые данные остаются на месте. Содержимое всей папки выпуска нужно сохранять рядом с exe.

`node scripts/verify-package.mjs` проверяет запуск, значения флагов защиты и отказ при подмене ASAR, затем восстанавливает архив. Модель защиты, ограничения, источники фильтров и детали проверок описаны в `SECURITY.md`.

## Передать другу

Отправить `Nocturne-Setup-<версия>-x64.exe`: это один установочный файл для Windows x64. Друг запускает его и проходит обычную установку без Node.js и прав администратора. По умолчанию приложение устанавливается в `%LOCALAPPDATA%/Programs/Nocturne`; ярлык на рабочем столе можно выбрать в установщике. Удаление программы сохраняет пользовательские профили.

Альтернатива — распаковать переносной ZIP целиком и открыть `Nocturne.exe`. В папке выпуска есть `START-HERE.txt`. Профили, API-ключи и пароли отправителя не включаются в установщик или ZIP.

Для сборки без замены уже запущенного выпуска: `node scripts/package.mjs --versioned`, затем `npm run installer`. Последняя команда использует переносимый Inno Setup 6.7.3: путь задаётся через `INNO_COMPILER`, по умолчанию `.tools/inno-portable/tools/ISCC.exe`. SHA-256 установщика записывается рядом с exe. Ни установщик, ни приложение пока не имеют подписи издателя Nocturne.

Настройки → Безопасность → «Подключить облачную защиту Google»: три шага, ссылки на Google Cloud и официальную инструкцию, поле собственного ключа и «Проверить и включить». Проверка делает реальный запрос к выбранному API с фиксированным адресом `https://example.com/`, даже если защита ещё выключена. Автоматическое включение происходит только после успешного ответа. Сеть, отключённый API, ограничения ключа и квоты показываются отдельными объяснениями. Нужен собственный Google Cloud API-ключ; обычный вход в аккаунт его не создаёт. Google Console открывается в системном браузере.

`node polish-smoke.cjs` проверяет центровку SVG-кнопок при двух размерах окна и сценарии подключения (тестовые ответы API, без реальных ключей). Иконки интерфейса используют общую SVG-сетку; фавиконки по-прежнему берутся с сайтов.
