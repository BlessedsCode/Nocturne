Импорт готового файла CSV
ИМПОРТ ИЗ ДРУГОГО БРАУЗЕРА

Chrome, Edge, Firefox, Zen Browser и совместимые CSV-экспорты.

  1. Открой менеджер паролей старого браузера.
  2. В его настройках выбери экспорт в CSV.
  3. Выбери этот файл кнопкой ниже.

На диске хранятся только зашифрованные данные. Заполнение — по твоему нажатию на точном HTTPS-адресе сайта, без отправки формы.

Основные и поиск

При запуске

Открывать сайты из последнего сеанса. Если выключено — открывается главная.

Поиск

Используется в адресной строке и поиске на главной.

Вводимый запрос отправляется выбранной поисковой системе. История остаётся на этом устройстве. Адреса сайтов не отправляются для подсказок.

Движение интерфейса

Управление вкладками

Экономия памяти (Memory Saver)

Выгружает страницы фоновых вкладок из RAM. Сохраняются адрес, название, иконка и позиция страницы. При возвращении на вкладку страница моментально загружается.

Сайты-исключения (никогда не усыплять)

Вкладки с этих сайтов не будут выгружаться в спящий режим.

Открытие ссылок

Применяется к ссылкам, открывающим новое окно, и команде «Открыть в новой вкладке».

Закрытие вкладки

По умолчанию выбирается соседняя вкладка справа.

Безопасность

Реклама и интеграции

Движок Ghostery · EasyList / EasyPrivacy. Блокировка запросов и скрытие рекламных элементов без расширений.

Пропуск спонсорских интеграций по разметке сообщества. После пропуска можно нажать «Вернуть». Intro и outro не пропускаются.

Данные SponsorBlock: https://sponsor.ajay.app/ · CC BY-NC-SA 4.0.

При открытии ролика SponsorBlock получает первые 4 символа SHA-256 его ID и твой IP. Аккаунт и API-ключ не нужны.

Если сайт работает неправильно, добавь его в исключения ниже и перезагрузи страницу. Полная незаметность для анти-AdBlock не гарантируется.

Защита от опасных сайтов

HTTPS шифрует соединение, но сам по себе не подтверждает честность сайта. Локальные адреса localhost / loopback доступны по HTTP.

Списки HaGeZi TIF Mini и Multi Light · GPL-3.0. Проверка доменов выполняется локально; обновления скачиваются с GitHub каждые 8 часов.

Проверка загрузок

Проверка выполняется после загрузки. Подозрительный результат блокирует открытие из Nocturne. Файл, который Defender не смог проверить, не помечается безопасным. Загруженным файлам добавляется метка Windows «из интернета», если файловая система это поддерживает.

Подключить облачную защиту Google

  1. Получи свой ключСоздай проект Google Cloud, включи Safe Browsing API и создай API-ключ. Ограничь его только этим API.
  2. Вставь ключ нижеУ каждого пользователя свой ключ. Он сохранится зашифрованным только в его профиле Windows.
  3. Проверь и включиОтправим Google тестовый адрес example.com. Защита включится только после успешного ответа.

Дополнительная проверка переходов и источников загрузки. Требуется свой API-ключ. Полные проверяемые адреса, включая параметры запроса, передаются Google; локальные адреса исключены.

Возможны ошибки определения: опасный сайт может быть пропущен, а безопасный — ошибочно отмечен. Для личного использования выбери Safe Browsing; при монетизации нужен Web Risk.

Ключ хранится зашифрованным средствами Windows. Если включённая проверка недоступна, переход останавливается с объяснением.

Исключения рекламы и трекеров

Разрешить рекламу и сторонние трекеры на указанном сайте. Блокировка опасных доменов продолжит работать.

Обновления и изоляция

Песочница Chromium и изоляция сайтов включены. Сайты не имеют доступа к Node.js; ошибки сертификатов не обходятся.

Новые выпуски Nocturne можно проверить и скачать в разделе «О браузере». Проверка версии движка не устанавливает обновления.

Заблокированные запросы

В журнале этого запуска сохраняются только домены, причина и время, без полных адресов.

Приватность и защита

Данные просмотра

Do Not Track передаёт сайтам предпочтение. Сайты сами решают, учитывать ли его.

Разрешения сайтов

В режиме «Спрашивать» доступ выдаётся через подтверждение для HTTPS-сайта и действует до закрытия браузера.

Удалить данные браузера

Пароли, избранное и закреплённые ссылки сохраняются.
